# SIO 文章用歷史案例快照

`usSentimentHistoryExamples.json` 僅包含 2020 疫情與 2022 市場修正的固定案例。

- 來源：既有 `/api/composite-historical-data` 公開歷史回應，未帶登入憑證；2026-10-08 取得。
- 取樣欄位：`date`、`compositeScore`、`spyClose`。沿用產品的 SPY 歷史價格序列，未重算或製造價格。
- 案例範圍：2020-01-01 至 2020-08-31、2022-04-01 至 2023-03-31，共 419 個交易日。
- 低點規則沿用 `MarketSentimentIndex/historicalLowPointUtils.js`：最低 12% 分數、前後 45 天局部低點、至少相隔 60 天。本快照的百分位比較基準固定為 2019–2023 年，共 1,258 筆資料；不是產品即時更新的全歷史比較基準。
- JSON 記錄比較基準、門檻、規則及原始歷史回應的 SHA-256，方便追溯。

這些橘點是完整資料回看後的情緒標記，不能解讀為當時即可確認的股價底部。2020 年情緒標記在 4 月，晚於案例中的 SPY 3 月低點；2022 年保留 7 月、10 月與年底的標記，以及 7 月訊號後仍持續下跌的價格。

文章同步引用固定 JSON，沒有歷史 API 請求或自動更新。公開案例不可帶入最新資料；更新時需先確認日期上限與完整事件走勢，並執行 `SentimentHistoryExamples.test.js` 和 copy-hygiene。測試限制快照日期不晚於 2023-12-31 且總點數少於 600。
