## Japanese terminology decision (2026-11-26)

- `Market Sentiment` / `市場情緒` → `市場心理` — user-approved canonical Japanese term for navigation, feature names, FAQs, indicators, articles, and notifications. Avoid using `市場センチメント` as a synonym.
- `Market Sentiment Composite Index` / `市場情緒綜合指數` → `市場心理総合指数` — preserves the composite-index meaning while using the approved `市場心理` term.
