# Korean review — non-JSON product copy

These strings are currently created directly in React components/configuration or generated by formatting helpers, rather than read from `translation.json`. They must be localized alongside the 2,265 JSON strings. This file is a proposal only; no runtime code has been changed.

## Market sentiment: Taiwan gauge explainer (`marketConfigs.js`)

**Title**

`대만 시장 공포·탐욕 지수 안내`

**Subtitle**

`이번 종합 점수는 {{currentCompositeScore}}점이며, 전체적으로 {{currentCompositeSentimentLabel}} 쪽에 가깝습니다. 대만 시장의 9개 신호를 종합해 0~100점으로 나타냅니다. 먼저 전체적인 심리를 확인한 다음, 점수에 영향을 준 변화를 살펴보세요.`

1. **대만 시장의 다양한 심리 신호를 종합합니다**

   `옵션, 신용융자와 대주, 외국인 선물 포지션, 환율, 모멘텀 및 시장 참여도를 함께 살펴 대만 시장의 위험 선호를 파악합니다. 각 신호의 방향이 서로 다를 수 있으므로 종합 점수를 통해 먼저 전체적인 흐름을 확인할 수 있습니다.`

2. **심리가 극단에 도달했는지 살펴보세요**

   `점수가 낮으면 종합 결과가 공포 쪽에, 높으면 탐욕 쪽에 가깝다는 뜻입니다. 수치가 극단적인 수준에 도달하면 개별 지표를 열어 어떤 신호가 점수에 영향을 주었는지 확인하고 대만 가권지수의 흐름과 비교해 보세요.`

3. **데이터로 추격 매수와 투매 충동을 점검하세요**

   `시장이 급락할 때 매도하고 싶거나 급등할 때 기회를 놓칠까 걱정된다면 먼저 데이터로 돌아가 보세요. 심리 점수, 지표 구성 및 과거 위치를 비교한 뒤 기존 자산 배분을 조정할지 판단하세요.`

## Other runtime-generated content

- `MarketSentimentIndex.getIndicatorDetailSummary` has an English fallback paragraph for indicator keys without a dedicated translation. Korean implementation should use the generic summary above for `ko-KR`; do not display Chinese copy.
- `PriceAnalysis.js` receives stock/company names from market data. Prefer an official English display name (`nameEn`) or the provider's canonical name when Korean company-name localization is not available. Keep symbols and tickers unchanged; do not machine-translate brand names.
- `AnnouncementCooldown` date strings and `AnnouncementDevTools` text are development diagnostics only, not public production UI. If they are exposed in a Korean development environment, use `Intl` `ko-KR` for the diagnostic date/time but do not treat those developer-only Chinese literals as part of the public translation inventory.

## Publication and behavior notes

- Use Korean strings only when the selected UI locale is `ko-KR`; do not replace English fallback strings for unsupported locales.
- The current Taiwan market explainer is specific to the Taiwan market. Do not reuse it for the US market.
- `{{currentCompositeScore}}`, `{{currentCompositeSentimentLabel}}`, `{{hours}}`, `{{duration}}`, `{{percentage}}`, and other listed tokens are illustrative placeholders for source variables; their exact source variable names must be retained when implemented.
- These proposals are not included in the 2,265 JSON key count and must be implemented/tested separately after translation approval.
