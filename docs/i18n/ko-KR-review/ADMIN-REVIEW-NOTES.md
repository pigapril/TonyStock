# 05-admin Korean review notes

All translations in `05-admin.ko-KR.json` are proposals pending user review and approval. The notes below are limited to terminology or semantics that could materially affect administration, permissions, security, or user eligibility.

| Key | Original Chinese | Proposed Korean | Issue / context needed |
|---|---|---|---|

Keep this term consistent if approved. |

Confirm whether the gate checks an administrator role/allowlist or only authentication; do not change this to “로그인 필요” unless authentication is the actual condition. |
